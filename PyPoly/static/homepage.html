🌟 核心遊戲特色

個人角色自訂義

支援 3D 角色即時預覽與全方位互動，並內建外觀顏色編輯、快速風格套色與臉部五官自訂功能，讓每位玩家都能打造獨一無二的專屬像素分身！

手勢影像辨識

透過鏡頭即時捕捉手勢動作，將肢體互動無縫轉換為遊戲指令與答題機制，擺脫傳統鍵盤與滑鼠的束縛，打造身歷其境的沈浸式學習體驗。

房產投資挑戰

踩中地圖格子並回答 Python 題目，獲得金幣並收購對應的知識點房產，逐步建立屬於你的程式帝國，在競爭中累積實戰財商與程式邏輯。

總資產結算獲勝

遊戲結束後自動結算房產總值與持有金幣，總資產最高者勝出！全面考驗玩家的投資策略、資金調度與程式實力的雙重對決。

學習統計與 AI 導師

系統自動記錄答題表現與知識點掌握度，並在答錯時由 AI 導師即時提供專屬提示與解析，精準引導並提升學習成效。

豐富題庫與手冊

內建多維度 Python 學習手冊與動態題庫，涵蓋基礎語法到進階概念，搭配即時回饋與詳盡解析，讓自主學習更有效率。

教師審核與申請

提供專屬教師身分申請與班級、題庫管理審核機制，方便教育工作者將平台應用於課堂教學，輕鬆追蹤與管理學生的學習進度。

❓ 常見問題 (FAQ)

Q1: 遊玩本平台需要準備什麼特殊設備嗎？ ▼
只需要一台配備有網路攝影機 (Webcam) 的電腦或筆電，以及標準的網頁瀏覽器即可順暢遊玩與進行手勢辨識！
Q2: 老師該如何申請教師端帳號並審核開通？ ▼
您可以先完成一般帳號註冊，並於系統內提交「教師身分審核申請」。經管理員審核通過後，即可解鎖教師端專區權限，進行建立班級、指派題庫與追蹤學生的學習統計數據。
Q3: 完全沒有 Python 基礎的新手可以玩嗎？ ▼
當然可以！平台內建由淺入深的 Python 學習手冊與基礎題庫，搭配 AI 導師的即時引導，非常適合零基礎的初學者邊玩邊學。
