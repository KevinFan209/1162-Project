# 棋盤編輯器 更新內容

## 更新日誌

### 2026-06-10

#### 新增功能
- **復原 / 重做**：工具列新增「↶ 復原」「↷ 重做」按鈕，支援鍵盤快捷鍵 `Ctrl+Z`（復原）與 `Ctrl+Y` / `Ctrl+Shift+Z`（重做），可還原編輯操作。
- **在此格後插入格子**：新增「⤵ 在此格後插入」按鈕，可於選取的格子之後插入新格子，方便調整路徑順序。
- **自動排版產生器**：新增「🧭 自動排版」功能，可依形狀（▭ 矩形 / ◯ 圓形 / 🌀 螺旋）、格子數、間距與高度模式（平坦 / 隨機起伏）一鍵產生整盤棋盤格局（會取代現有格子，可用「復原」還原）。

#### 程式碼重構
- 將原本內嵌於 `board-editor.html` 的樣式與程式碼抽離為獨立檔案：
  - `board-editor.css`：介面樣式
  - `board-editor.js`：編輯器邏輯
- 新增 `BoardStyle/` 資料夾，作為匯入棋盤檔案時的預設目錄。

> 註：`game.html` 內容未變更。

## 初始版本（115-05-29）

### 新增檔案

#### board-editor.html — 棋盤編輯器
視覺化棋盤設計工具，支援以下功能：
- **2D 編輯**：在畫布上拖曳格子調整位置，並可啟用格線吸附
- **3D 預覽**：切換至 Three.js 3D 預覽，支援旋轉、縮放、平移
- **格子屬性編輯**：可調整格子的座標、高度、大小、類型與標籤文字
- **匯入 / 匯出 JSON**：將棋盤設定儲存為 JSON 或從檔案載入
- **套用到遊戲**：將棋盤設定寫入 `localStorage`，供 `game.html` 讀取使用
