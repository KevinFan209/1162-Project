### database.py — 資料庫從 MySQL 改為 SQLite

**原版：** 連接 XAMPP MySQL
```python
SQLALCHEMY_DATABASE_URL = "mysql+pymysql://root:@localhost/pypoly_db"
engine = create_engine(
    SQLALCHEMY_DATABASE_URL,
    pool_size=20, max_overflow=30, pool_timeout=60, pool_recycle=1800, pool_pre_ping=True

```

**現版：** 改用本地 SQLite 檔案（`pypoly.db`）

```python
_DB_PATH = os.path.join(os.path.dirname(os.path.abspath(__file__)), "pypoly.db")
SQLALCHEMY_DATABASE_URL = f"sqlite:///{_DB_PATH}"
engine = create_engine(SQLALCHEMY_DATABASE_URL, connect_args={"check_same_thread": False})
```

## 三、修改的前端頁面

### static/game.html — 角色渲染系統 + 返回大廳邏輯

#### 新增（角色自定義整合）
完整程式碼已獨立到 `static/pypoly_char.js`，包含：
- `const pendingCharData = {}` 緩衝對手角色資料
- `makeDummyTexture()` — 空白佔位貼圖
- `loadFaceTextureIntoMat(mat)` — 從 localStorage 載入人臉貼圖
- `applyCharDataToMat(mat, data)` — 套用對手傳來的角色資料
- `emitCharData()` — 透過 Socket.IO 廣播自己的顏色+人臉
- `CHAR_VERT` / `CHAR_FRAG` GLSL shader（Y 軸分區上色 + 人臉貼圖）
- `loadPlayerModels()` — 載入 minecraft_-_steve.glb 並套用自定義材質
- `socket.on('char_data_sync', ...)` 監聽器

#### 新增（返回大廳前先離房）
```javascript
async function leaveCurrentRoom() {
    const username = localStorage.getItem('username');
    const activeRoom = JSON.parse(localStorage.getItem('pypoly_active_room'));
    if (!activeRoom || !username) return;
    const code   = activeRoom.code;
    const isHost = activeRoom.hostId === username;
    try {
        if (isHost) {
            await fetch(`${API_URL}/rooms/delete/${code}`, { method: 'DELETE' });
        } else {
            await fetch(`${API_URL}/rooms/leave/${code}?username=${encodeURIComponent(username)}`, { method: 'POST' });
        }
    } catch(e) {}
}
async function returnToLobby() {
    await leaveCurrentRoom();
    window.location.href = 'lobby.html';
}
```

#### 替換（舊角色系統 → 新）
- 原本讀取 `char1.glb` / `char2.glb` 的固定模型邏輯，全數替換為 `loadPlayerModels()`

#### 全域 API URL 動態化
```javascript
// 原版（硬編碼）：
const API_URL = "http://10.178.72.76:8000";
// 現版（動態偵測）：
const API_URL = window.location.protocol !== 'file:' ? window.location.origin : 'http://localhost:8000';
```
