=== 第6頁 ===
    系統架構
  ● 三層式架構（Three-Tier Architecture）
  ● 【表示層】
    HTML / CSS / JavaScript / WebSocket
    Three.js 3D 棋盤介面
  ● 【業務邏輯層】
    遊戲邏輯（FastAPI / Node.js）
    影像辨識（Python + OpenCV）
    使用者管理（JWT / bcrypt）
  ● 【資料層】
    MySQL / PostgreSQL（持久化）
    Redis（即時遊戲狀態快取）
    AWS S3 / MinIO（靜態資源）

=== 第7頁 ===
    系統架構
  ● 模組設計
  ● 客戶端模組
    登入與大廳　使用者註冊、登入、遊戲等候室
    主遊戲棋盤　地圖渲染、玩家移動、事件觸發
    互動任務　　題目顯示、作答介面、即時回饋
    遊戲結算　　分數計算、排名顯示、歷史記錄
  ● 伺服器端模組
    使用者管理　帳號驗證、JWT 權限管控
    遊戲邏輯　　回合管理、移動判斷、金錢計算
    題目管理　　題庫維護、難度分級、自動評分
    影像辨識　　手勢偵測、骰子偵測、ArUco 標記
  ● 後台管理模組
    Question CMS（題目管理）
    Vision Debugger（辨識偵錯頁）
    Game Analytics（遊戲數據監控）
    User Management（玩家帳號管理）

=== 第8頁 ===
    系統架構
  ● 使用技術 ＆ 部署架構
  ● 使用技術
    前端　HTML5 / CSS / JS / WebSocket / Three.js
    後端　Python / FastAPI / Node.js / OpenCV / Socket.IO
    資料庫　MySQL / PostgreSQL / Redis
    安全　JWT / bcrypt / HTTPS / 防 XSS / 防 SQL Injection
  ● API 設計
    POST  /api/auth/login  ·  GET  /api/game/:id
    POST  /api/game/start  ·  POST  /api/answers/submit
    GET   /api/leaderboard  ·  GET  /api/questions/random
  ● 部署環境
    CloudFlare → Nginx → Node.js (PM2) + FastAPI (Uvicorn)
    資料庫：MySQL + Redis　　儲存：AWS S3 / MinIO
